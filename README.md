# LEVEL2의 해설

## 10. QueryDSL 을 사용하여 검색 기능 만들기

처음에는 하나 씩 RequestParam으로 받아주려고 했으나 생각보다 양이 좀 많아서 깜짝 놀랐습니다.
그러다보니 '아, 이거 dto가 편하겠다' 라는 생각이 들어서 ModelAttribute로 받기로 하였습니다.

이거는 parm이나 x-www.form 어느 쪽으로 받는 게 더 일반적이고 실무적인지 꼭 좀 알려주셨으면 합니다.
그리고 이번에 쿼리 DSL에 조건과 null 잡는데 좀 많이 고생을 했습니다.
위에 쿼리문 자체를 적어주는 건 별 문제 없었는데 조건을 적어주면서 null까지 잡고, 람다식으로 적으면서 삼항연산자까지 사용하였습니다.
